## New patterns for UI_Standards.md (propose before build)

1. **File dropzone** — dashed card, 44px+ CTA, progress rows per file with stage text (uploading → scanning → extracting → ready).
2. **Preview toolbar** — dark bar, 44px touch buttons (prev/next/zoom/find), page indicator.
3. **Version timeline** — numbered nodes, current highlighted, per-row actions, restore-requires-reason.

## Deviations from mockup

- **Upload view built at T-10 freeze** (`documents/create.blade.php`): the mockup §02 specified it but only the POST endpoint existed. Built faithful to the mockup — dropzone, per-file progress rows with stage text, scan banner.
- **Per-document section tabs** (T-10, `documents/partials/doc-tabs.blade.php`): Preview · Versions · Share · Activity via `<x-ui.sub-nav>` — new chrome surfacing the C-14 Activity tab; Share tab gated to `:manage`.
- **Hold banner on preview** (T-10): active legal holds render as a `warn` banner on the preview page (mockup predates it).
- **Activity tab + CSV export** (T-10, C-14): `documents/activity.blade.php` + `documents.activity.export` — read models over `audit_events`.
- **Thumbnails toggle**: `shrink-0` so the label never compresses on 390px (visual fix found by the C-15 gate).
