## Accessibility

- Every control labeled through its wrapper (`label[for]` = input `id`) — asserted by C-06.
- Focus-visible: 2px `--vl-info` outline on all interactive elements.
- Contrast pairs (all ≥ 4.5:1 for text): `--vl-ink` on white 14.5:1 · `--vl-text` on white 14.5:1 · `--vl-mut` on white 5.5:1 · white on `--vl-ink` 14.5:1 · `--vl-brass` on white 4.7:1 (large/bold only — body text uses `--vl-ink`) · `--vl-ok` on white 5.0:1 · `--vl-bad` on white 5.9:1 · `--vl-info` on white 6.8:1. Soft tints are backgrounds only, always paired with their strong tone as text.
- Keyboard: modal traps focus, Escape closes; nav drawer is keyboard-operable; skip-link in the shell.
- Target: WCAG 2.1 AA on new surfaces.

## Accessibility audit — T-07 (2026-10-07)

- **C-06 complete** (`test_all_form_controls_have_associated_labels_complete`):
  `label[for]` matches the control `id` for all four wrappers (`field`,
  `select`, `checkbox`, `textarea`) — default id derivation, custom `id`
  overrides, and error states (error node `id="{id}-error"` wired through
  `aria-describedby`).
- **Focus-visible**: base CSS declares `:focus-visible { outline: 2px solid
  var(--vl-info); outline-offset: 2px; }`; asserted present in both
  `resources/css/app.css` and the Vite-compiled bundle
  (`test_focus_visible_styles_render_on_interactive_elements`).
- **Contrast audit** (`test_contrast_pairs_meet_aa_and_match_recorded_values`):
  hex values parsed from the `@theme` block, WCAG 2.1 ratios computed vs
  white — no regressions, all >= 4.5:1:

  | Pair | Computed | Recorded |
  |---|---|---|
  | `--vl-ink` on white | 14.5:1 | 14.5:1 |
  | `--vl-text` on white | 14.5:1 | 14.5:1 |
  | `--vl-mut` on white | 5.5:1 | 5.5:1 |
  | `--vl-brass` on white | 4.7:1 | 4.7:1 |
  | `--vl-ok` on white | 5.0:1 | 5.0:1 |
  | `--vl-bad` on white | 5.9:1 | 5.9:1 |
  | `--vl-info` on white | 6.8:1 | 6.8:1 |

  `--vl-brass` stays large/bold-only per the original note (body text uses
  `--vl-ink`); soft tints remain backgrounds only.
- **Keyboard walk** (`test_modal_traps_focus_and_closes_on_escape`,
  `test_mobile_drawer_is_keyboard_operable`,
  `test_skip_link_targets_main_content_landmark`): modal renders
  `role="dialog"` + `aria-modal` + `aria-labelledby`, `x-trap` focus
  containment, Escape closes; drawer closes on Escape, traps focus, and its
  icon-only open/close buttons carry accessible names; the shell skip link
  targets `<main id="vl-main">` on the live `/_patterns` page.
