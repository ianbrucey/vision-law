## Layout

- **Desktop:** single centered column, max-width 1120px (the standing
  layout law), sections stacked: nav → hero (copy left, component
  vignette right at ≥820px) → platform steps → packs → trust → CTA →
  footer. Background: the theme's aurora wash over `--bg`.
- **390 px:** everything stacks; the vignette follows the hero copy; pack
  and trust cards go single-column; the theme switcher stays reachable
  in the nav (it wraps under the brand row, never hidden behind a menu);
  no horizontal scroll; tap targets ≥ 44px.

## Theme behavior

- Default render: **Ocean Deep** (013-D05), painted correctly on first
  load — the default token set is the `:root` fallback, so there is no
  flash of another theme.
- The switcher swaps the root `data-vs-theme` attribute; every surface
  cross-fades on `--ease` / `--dur-3`. No reload, no request.
- The mockup carries **seven representative sets live**: Ocean Deep
  (default), Aurora, Calm Deep Ocean, Earth · Grove, Regal · Blue & Gold,
  Matte Slate, Daylight — spanning glass, calm, matte-flat, and light so
  Ian can judge the families. The build carries all 25 per the contract;
  the five light sets are held out of the production switcher until
  013-O02 is decided (they are still defined and tested).
- Matte sets are genuinely flat: opaque surfaces, no backdrop blur, no
  glow elevation. Light sets invert text/surface tokens; signal meanings
  do not change.

## Motion rules (013-D07, contract §Motion contract)

- On load and on scroll into view, sections rise ~14px and fade in on
  `--ease` / `--dur-3`, staggered lightly — graceful, never a pop.
- Theme changes cross-fade; panels and cards never change size or
  position during a theme change (color only).
- `prefers-reduced-motion` disables the entrance and cross-fade layer;
  the page is complete and static without it.

## Accessibility

- Keyboard-navigable; the theme switcher is a real `<select>` with a
  visible label; focus-visible styles on all interactive elements.
- State chips and bands pair color with text labels — color is never the
  only signal (standing law).
- Contrast: every theme's `--txt` on its surfaces must hold WCAG 2.1 AA
  for body text; the light sets are the risk and are QA'd individually
  (brief pre-mortem).
- Target: WCAG 2.1 AA on new surfaces.
