## States

- **Empty:** "No matters yet" with New matter CTA; empty timeline/comments/team sections with next actions.
- **Loading:** skeleton rows on the list table (deferred to implementation detail; mockup shows static).
- **Validation:** inline field errors (§05 error state); transition modal guards.
- **Denied:** §06 generic page.
- **Conflict:** concurrent transition — second writer gets 409 with legal next states; UI surfaces the modal with refreshed state.
- **Success:** toast on create/transition/assign ("Matter MAT-2026-004 created"); lands on the detail page.
- **Destructive:** delete = danger button + consequence line ("Soft-deleted matters are recoverable by org admins for 30 days."); revoke grant = same pattern.

## Data volume & layouts

- **Realistic volume:** list shows 25+ rows in implementation (mockup shows 3 for readability); timeline paginated at 20.
- **Desktop layout:** 1120px max content, two-column cards on detail.
- **390 px layout:** single column; tables scroll inside their card; action buttons full-width.

## Accessibility

- Keyboard-navigable tabs and modal (focus trap per 002); visible focus; state badges pair color with text.
- All timestamps absolute + relative; timezone is the viewer's.
- Target: WCAG 2.1 AA on new surfaces.
