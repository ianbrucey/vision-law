## Screens (mockup scope, fixed)

1. **Login** (`/login`) — email + password, "forgot password" link, 2FA
   challenge variant, validation-error state, lockout state (429 with
   retry-after messaging, no account-enumeration wording).
2. **Registration** (`/register`) — name/email/password (+ invitation token
   when present); unverified-notice state ("check your email"); duplicate-email
   yields the generic message, never "already registered".
3. **Password reset** (`/forgot-password`, `/reset-password/{token}`) —
   request form, sent-confirmation (generic), reset form, expired-token state.
4. **MFA enrollment** (`/user/two-factor-authentication`) — QR + manual code,
   confirm-with-code step, backup codes display (one-time, copy + download),
   disable flow requiring password re-authentication.
5. **Sessions** (`/sessions`) — current session highlighted; per-session revoke;
   revoke-all (destructive confirmation).
6. **Admin: users** (`/admin/users`) — org user table (50-row density in
   mockup), invite dialog (email + role + optional matter scope), role
   assignment, deactivate (destructive confirmation), validation states.
7. **Admin: teams** (`/admin/teams`) — team list, member management.
8. **Admin: invitations** (`/admin/invitations`) — pending invitations with
   revoke; expired shown distinctly.
9. **Admin: audit viewer** (`/admin/audit-events`) — filter bar (actor, object
   type, action, date range, free text), paginated table, watermarked export
   action, empty-result state.
10. **Matter grant management** (`/matters/{matter}/grants` section) —
    grant list, add-grant dialog (subject type user/team, role, optional
    expiry), revoke (destructive confirmation), expired grants shown
    distinctly.
11. **Denied state** — generic "not found" page for 404-not-403 cases
    (identical whether the resource exists or not); plain 403 page for
    insufficient-role cases on visible resources.

## Components

- Login/registration/reset/2FA → Blade views (Fortify actions), styled per
  `docs/UI_Standards.md` (provisional — standards are [P]).
- Admin tables → `<x-ui.*>` namespace when it exists; until then, plain Blade
  + Tailwind following the standards' markup rules.
- Roles rendered: `org_admin` sees admin nav; all other roles see only their
  permitted surfaces; denied elements are **absent**, not disabled-with-secrets.
- Mockup section mapping: to be filled when `05-ui-mockup.html` is built.
- Approved deviations from mockup: none yet.

## States (every screen shows each applicable state in the mockup)

- **Empty:** e.g. audit viewer with no matching events — "No events match these filters."
- **Loading:** skeleton rows on admin tables.
- **Validation:** inline field errors per the contract's error catalog.
- **Denied:** generic not-found vs. plain 403 per the leak rules.
- **Conflict:** N/A for this feature (no concurrent-edit surfaces) — recorded explicitly.
- **Success:** e.g. invitation sent → toast naming the consequence ("Invitation sent to … — expires in 7 days").
- **Destructive:** revoke-all-sessions, deactivate user, revoke grant — confirmation naming the consequence.

## Data volume & layouts

- **Realistic volume:** 50-row user table, 200-row audit table page.
- **Desktop layout:** described in mockup.
- **390 px layout:** responsive web; auth forms single-column; admin tables collapse to cards.

## Accessibility

- Keyboard-navigable; visible focus; state badges pair color with text labels.
- All timestamps absolute + relative; viewer's timezone.
- Target: WCAG 2.1 AA on new surfaces.
