## Public layout contract (`resources/views/layouts/public.blade.php`)

Minimal shell shared by all public pages (built in T-01). Consumption is
component-style, mirroring `<x-layouts.app>`:

```blade
<x-layouts.public title="Page title">
    …whole page…
</x-layouts.public>
```

- **Prop:** `title` (string, default `"Vision Law"`) — the `<title>`.
- **Slot:** `$slot` (required) — the whole page. No other named slots.
- Shell contents: `<html lang="en">`, charset, meta viewport, `@vite`
  (app.css + app.js), skip link (`#vl-main`), toast mount (`<x-ui.toast />`
  — internal, not a slot), `{{ $slot }}`.
- No app topbar, no `org`/`userMenu`/`nav` slots — public pages carry no auth
  session data (C-04). Marketing nav and footer live in the page views /
  their partials, so dark-section ownership stays per-page (003-D01).
- The 003-D01 exception scope is recorded in the layout's docblock: dark
  cinematic tokens opt-in per section in page views; the layout itself is
  neutral.

## New tokens (003-D01)

Dark cinematic palette for the marketing landing only, added to `resources/css/app.css` `@theme` and recorded in `docs/UI_Standards.md`:

| Token | Value | Used for |
|---|---|---|
| `--vl-dark-0` | `#04060C` | Hero/nav/footer/footer-CTA base |
| `--vl-dark-1` | `#0A1424` | Hero/CTA gradient end |
| `--vl-neon` | `#35A2FF` | Accent: eyebrow, CTAs, glyphs |
| `--vl-neon-deep` | `#1B6FD6` | CTA gradient end |
| `--vl-dark-text` | `#EAF2FA` | Text on dark |
| `--vl-dark-mut` | `#9DB1C7` | Secondary text on dark |

Rule: used only on the marketing landing (nav, hero, trust strip, final CTA, footer). Everything behind auth stays light-only. Door 7 (no `dark:` variants, no `class="dark"`) is unchanged — the dark hero uses these tokens, not dark-mode variants.
